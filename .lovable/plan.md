# فصل العملات نهائياً + حساب لكل عميل بالريالين + تشغيل آلي مترابط

## 1) فصل العملات بشكل نهائي وحذف سعر الصرف

- حذف صفحة "أسعار الصرف" وزرها من الإعدادات، وحذف جدول أسعار الصرف من قاعدة البيانات.
- حذف حقل "سعر التحويل" من صفحة العملات (يبقى: الاسم، الرمز، وحالة العملة الافتراضية للعرض فقط).
- إلغاء أي تحويل أو جمع بين العملات في كل التطبيق:
  - الرئيسية: بطاقات أرصدة مستقلة لكل عملة، بدون "الإجمالي بالعملة الأساسية".
  - صفحة العميل: مسار مستقل لكل عملة (رصيد، معاملات، كشف حساب، رسائل).
  - التقارير والمتابعة والتصنيف الذكي للعملاء: نتائج منفصلة لكل عملة.
  - كشوف الحساب (Excel/PDF) والرسائل: ملف/رسالة لكل عملة كما هو، بدون أي مبلغ محوَّل.
- الترتيب داخل الشاشات يصبح: العملة أولاً ثم البيانات، بحيث لا يظهر أي رقم بدون عملته.

## 2) كل عميل جديد له حساب بالريال اليمني وحساب بالريال السعودي

- ضبط العملات الافتراضية للحساب: ريال يمني + ريال سعودي (وإمكانية إضافة غيرها يدوياً).
- عند إضافة أي عميل (يدوياً، أو عبر الاستيراد، أو عبر الإضافة الذكية) يتم فتح حسابين تلقائياً برصيد صفر: ريال يمني وريال سعودي — عبر تجهيز تلقائي في قاعدة البيانات حتى لا يعتمد على الواجهة.
- في صفحة العميل تظهر دائماً تبويبتان للعملتين حتى لو كان الرصيد صفر، وكل تبويبة لها: رصيدها، معاملاتها، كشفها، وأزرار الإرسال الخاصة بها.
- العملاء الحاليون يتم فتح الحسابين الناقصين لهم أيضاً ضمن نفس التحديث.

## 3) التطبيق كجسد واحد موصول بشبكة عصبية

- "شبكة عصبية" واحدة للبيانات: أي إضافة/تعديل/حذف/رسالة تُحدِّث كل الشاشات المتأثرة فوراً (الرئيسية، العميل، المتابعة، التذكيرات، البريد الصادر، التقارير) بدون تحديث الصفحة.
- بث لحظي (Realtime) للعملاء والمعاملات والتذكيرات وقائمة الإرسال، مع تنظيف الاشتراكات لتجنّب أي استهلاك زائد.
- بقاء كل المنطق في الواجهة الخلفية؛ الواجهة الأمامية عرض فقط.

## 4) التشغيل الآلي (مؤتمت)

- دورة تلقائية دورية: توليد التذكيرات المستحقة، إرسال رسائل المتابعة حسب السياسة، الملخص اليومي، القواعد المتكررة، والنسخ الاحتياطي — كلها من المهام الخلفية القائمة.
- احترام أوقات الهدوء وحد الرسائل لكل عميل، ومنع التكرار.
- لوحة "حالة التشغيل الآلي" في الإعدادات: آخر تشغيل، ما تم إرساله، وما فشل مع سبب مبسط.

## التفاصيل التقنية

- ترحيلات قاعدة البيانات: حذف `exchange_rates`، إزالة الاعتماد على `currencies.rate` و`transactions.rate_at_tx` في الحسابات، تعديل دالة تجهيز العملات الافتراضية إلى (ريال يمني، ريال سعودي)، وإضافة دالة/محفّز لفتح حسابات العميل لكل عملة عند الإنشاء + تعبئة رجعية للعملاء الحاليين.
- تنظيف الكود: حذف `src/lib/money/rates.ts` و`src/routes/app.exchange-rates.tsx`، وإزالة `net_base` / `baseEquivalent` / `toBase` من `home.functions.ts` و`money/balances.ts` والمكونات المرتبطة.
- طبقة مزامنة موحّدة: hook مركزي للاشتراكات اللحظية + إبطال استعلامات TanStack Query لكل جدول متأثر.
